# Coffee Date Compatibility Test ☕

A fun, interactive coffee-themed compatibility test to ask someone out for a coffee date. Inspired by modern dating apps but with a personal touch.

## Features

- 🎨 Beautiful coffee-themed design
- 📱 Mobile-responsive interface
- ☕ Interactive coffee cup animation
- 📅 Calendar date picker
- 🎯 Fun compatibility quiz with "I trust your choice" options
- ✨ Animated elements and effects
- 📬 Form submission to Netlify
- 🔔 Optional ntfy.sh notifications

## How it works

1. Recipient holds the coffee cup animation to unlock the test
2. Takes a 4-question coffee compatibility quiz
3. Gets a "compatibility score" (spoiler: it's always high!)
4. Can schedule a coffee date with calendar and time selection
5. Submits their preferences via Netlify forms

## Deployment

This site is designed to be deployed on Netlify:

1. Connect your GitHub repository to Netlify
2. Deploy with default settings
3. Enable Netlify Forms in your site settings
4. Optionally customize the ntfy.sh topic for notifications

## Customization

- Update the quiz questions in the `quiz` array
- Modify the coffee preferences in the `schedule()` function
- Change colors by updating the CSS custom properties
- Personalize the messages throughout the site
